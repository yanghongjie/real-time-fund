## ADDED Requirements

### Requirement: Brand Name Display

The system SHALL display the brand name "基基宝" consistently across all user-facing interfaces.

#### Scenario: Page title displays brand name

- **WHEN** user opens the application in a browser
- **THEN** the browser tab title SHALL display "基基宝"

#### Scenario: Header displays brand name

- **WHEN** user views the application header
- **THEN** the brand name "基基宝" SHALL be displayed next to the logo

#### Scenario: Feedback email uses brand name

- **WHEN** user submits feedback through the feedback form
- **THEN** the email subject SHALL include "基基宝 - 用户反馈"
